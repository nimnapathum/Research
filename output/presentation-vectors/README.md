# Interim defense vector icons

All ten files are editable SVGs with a transparent 256 × 256 viewBox.

Palette: `#2A1A0E` dark brown, `#D4621A` rust, `#F4AE52` gold, `#FEF3E2` cream.

The icons cover the study flow: coding agent, code proposal, confidence, keep/reject decision, verification, security repair, final code, SQL injection, path traversal, and replay interview.
