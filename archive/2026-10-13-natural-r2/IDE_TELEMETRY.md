# Current capture capabilities

Protocol natural-2026-10-13-r2 uses the two scripts in the natural ZIP. `study/capture.mjs watch` saves initial and changed source snapshots, checking every two seconds. `snapshot` freezes a final copy and manifest; identity comes from `SESSION_INFO.json` rather than folder name. `study/rate.mjs` collects final security beliefs linked to that hash. The collector excludes likely secrets, hidden files, unsupported formats and symlinks and limits volume, so researcher file-coverage review is required.

The portal receives code/capture ZIPs, health, final manifest, rating, readable agent transcript and screen recording with task-specific hash receipts. Small rating/manifest files unlock the immediate after-task form. Receipts prove transfer; the independent archive audit checks code hashes and media still needs manual playback/readability checks.

Screen recording and Antigravity conversation export are separate host procedures. The natural ZIP does not automatically capture prompt/reply text, terminal commands, mouse speed, gaze, keyboard cadence, active editor focus or human acceptance events. Contextual event timing can be manually coded from video/transcript. Missing or ambiguous moments receive explicit uncertainty. A two-second code poll cannot yield millisecond acceptance latency.

The existing hook, pointer recorder and extension are prototypes for the older controlled route. A future optional natural hook can be added only after exact-version compatibility, noninterference, coverage and privacy are tested. Official hook/API documentation establishes possible interfaces, not complete data from every IDE version. Do not list pointer or hook metrics as collected unless the actual session records them.
