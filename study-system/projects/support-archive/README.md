# Support archive starter project

A tiny local API over 20 synthetic support tickets and text attachments. There are no external packages, remote services, accounts, or real user data. The planned study runtime is Node.js 24.21.0 LTS; test the exact setup before recruitment.

Run `npm start` and visit `http://127.0.0.1:4174/health` or `/tickets`. Run `npm test` for the starter endpoint. The researcher gives you the current checkpoint task sheet; `npm run test:q1`, `test:q2`, `test:f1`, and `test:f2` check ordinary feature behaviour after implementation. These checks are expected to fail before their respective features are built. You may inspect every file and perform additional checks.
