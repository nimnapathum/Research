# Debrief script — reconcile with the approved ethics wording

Use only after both tasks and the replay interview, so the explanation cannot affect measured decisions. The facilitator must use the paragraph matching the actual proposal provenance. Do not claim that constructed patches were generated naturally by the agent.

**Common text:** “Some proposed changes were selected because they might meet the security requirement and others because they might contain a SQL injection or path traversal weakness. We compared your estimate about the exact proposed code with an independent security review, and we will separately assess the final code. A first decision to keep code is not assumed to mean a weakness remained in your final submission. We are studying the workflow and code, not grading you personally. Your participation and right to withdraw follow the information sheet you received.”

**If every selected proposal is genuine, unmodified agent output:** “The displayed proposals came from recorded runs of the named coding agent on these tasks. We selected the proposals to balance secure and vulnerable examples. That balance does not represent the agent's natural error rate.”

**If any proposal is constructed or edited by researchers:** “At least some displayed proposals were prepared or edited by the researchers to create balanced examples. Your coding-agent conversation was real, but those particular displayed changes must not be described as spontaneous agent output. This study can test your review of proposals during agent-assisted work; it cannot estimate how often the agent itself produces these weaknesses.”

Ask: “Is there anything about the procedure or proposal source you would like clarified?” Answer factually. Do not identify a particular participant's missed weakness as a personal failure. Record that debrief occurred and any request to withdraw or receive later results under the approved policy. The disclosure must match the approved information and consent sheet; if approval covers only genuine agent output, do not run constructed-proposal participants under that approval.
