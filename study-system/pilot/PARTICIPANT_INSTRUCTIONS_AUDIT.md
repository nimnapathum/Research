## What participants see

| Surface | Guidance and behaviour |
| --- | --- |
| Sign in / account | Researcher-issued username and password; no email required. |
| Overview | One ordered session guide, pre-task form, two task cards, progress controls, and questionnaire availability. |
| Task page | ZIP download, task requirements, human work guidance, capture commands, finishing instructions, and seven upload inputs. Page navigation links jump to each section. |
| Capture setup | Run observer setup and watch, start video and code watcher, then start a fresh conversation. No separate study extension is needed in this workflow. |
| During coding | Agent can edit immediately. Participants can inspect, test, repair, and use documentation. A technical capture check does not require a code acceptance decision. |
| Finish | Stop editing, wait for the agent, save final snapshot, and rate that snapshot before researcher assessment feedback. Stop watchers and save video. |
| After-task form | Available after matching final manifest and rating uploads. Saving returns to this task's upload section; saved answers are displayed there. |
| Evidence uploads | Small files and form first; larger evidence next. Human-readable labels identify missing files. Receipts confirm storage; researcher reviews content quality. |
| Submit / Task 2 | All seven files required for submission. Task 2 requires Task 1 submission and after-task answers. |
| Final session form | Opens only after both submitted tasks and both after-task forms. Interview is conducted with the researcher. |
| ZIP instructions | START_HERE.md now has five numbered sections with the same setup, coding, rating, form, upload and submission order. |
| Legacy event upload | Hidden from natural participant navigation; direct access redirects to the overview. |

## Package versions

The first issued ZIP and its task materials are frozen. New participants receive the current observer-enabled package. Earlier frozen packages display a notice and manual transcript export guidance; downloading again does not add the observer or rewrite their bundled guide. Use a fresh rehearsal participant to inspect new ZIP guidance. Portal interface changes appear on refresh.
