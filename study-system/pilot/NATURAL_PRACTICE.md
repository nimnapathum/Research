# Neutral practice for the natural study

Use the same approximately five-minute practice before either measured task. It is an original procedural exercise, not a security lesson or a scored outcome.

1. In a separate throwaway folder, create `label.mjs` with `export function label(name) { return name; }`. Ask the agent to explain it, then ask it to trim spaces at both ends of the name. The participant may let it edit immediately and inspect or revise the change.
2. Run `node --input-type=module -e "import { label } from './label.mjs'; console.log(label('  Sam  '));"`. Confirm the participant can find the result and the agent's reply. Give setup help only. There is no keep/reject or probability question here.
3. Make a short screen-recording sample and save a readable task conversation with the exact method tested on that host. Replay the video and read the saved conversation. An IDE without a full export needs an approved fallback with explicit omissions; do not assume copied prose contains tool calls or every edit.
4. Explain that the measured project's watcher saves source snapshots and must run in a separate terminal. Show the capture commands without rehearsing SQL or file-access defences. Confirm the participant can locate the task page and upload controls.
5. Close the practice folder/conversation. Open a fresh conversation for Task 1. Log extra training/help. Practice outputs do not enter the main analysis.

Do not use the older `/practice` checkpoint reveal page for this protocol. The practice ends when setup is understood; it does not require a correct security solution.
