## Pilot gate still open

1. The hosted release has applied migrations `004_study_phase.sql` and `005_natural_assessments.sql` after a restricted backup and passed synthetic phase/assessment checks. The newer local analytics revision adds no migration. Keep rehearsal, pilot and main data separate.
2. Complete one actual Antigravity/Meet rehearsal on each intended host setup. Confirm raw prompt/reply coverage, both watchers, initial and final source snapshots, six uploads, a working Drive link, and that the researcher can retrieve and replay the exact files.
3. Run secure and vulnerable reference implementations for SQL injection and path traversal against the independent functional/attack probes; record unsupported cases and reviewer disagreement. Rehearse review on one natural output.
4. Pilot task contrast and form comprehension with the target cohort. Check observed acceleration/exploration episodes **without using verification frequency or security outcome to assign a mode**. Check difficulty, time, completion, interface bypass, and carryover by assigned condition. Freeze task, form, codebook and analysis revisions before main recruitment.
5. Establish an approved correction/withdrawal record. Uploads are intentionally immutable, but the portal has no audited replace/waive workflow. Do not silently overwrite or substitute evidence.
