# Natural-study data and figure plan

The current data tables and denominators are defined in [NATURAL_ANALYSIS_PLAN.md](NATURAL_ANALYSIS_PLAN.md). Quantitative data includes background/self-report, assignments, source hashes/times, probabilities, functionality/security labels and coded behaviour counts/durations. Qualitative data includes rating reasons, prompt/conversation content, video-supported intent and check sequences, replay explanations and deviation notes. Raw content and derived labels remain separate.

| Display | Meaning and required caveat |
| --- | --- |
| Recruitment and evidence flow | Approached through completed, with per-stream missingness and per-RQ usable counts. |
| Paired probability-score plot | One paired point/difference per complete assessable participant; show exclusions. |
| Confidence by final security | Split target-secure/vulnerable labels and class; show n and absent label groups. |
| Final feature outcomes | All planned features including missing/nonfunctional/unassessable; no missing-as-secure coding. |
| Check timelines | Agent application, human inspection, checks, repairs and final hash; uncertainty intervals remain visible. |
| Mode-time proportions | Known-next-step/option-seeking/mixed/unclear intent, with waiting/gaps separately shown. |
| Exposure-to-final flow | Confirmed insecure agent exposures only; zero exposures means not estimable. |
| Joint evidence table | Representative and contradictory patterns linking checks/security with replay explanation. |

Do not use a chart labelled cognitive mode from mouse speed or a chart labelled trust from acceptance counts alone. Class differences and observed-mode associations are exploratory. Previous controlled-review figures are [archived](archive/2026-10-13-controlled/DATA_AND_FIGURE_PLAN.md).
